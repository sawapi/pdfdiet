How it works

      
Most of a heavy PDF is images stored far sharper than they are ever shown, and fonts embedded many times over. pdfdiet fixes both, and only where it can prove the result.

      

        

          
          
Measured, not guessed

          
Every page is interpreted, through nested forms and soft masks, to measure the resolution each image is actually drawn at. A photo placed small gets downsampled; one shown full-page keeps its detail.

        

        

          
          
Images handled with care

          
Gray-looking scans drop to one channel, CMYK stays CMYK, black-and-white scans are recompressed losslessly. JPEGs that can't be beaten are still optimized losslessly, and the original is kept whenever it is smaller.

        

        

          
          
Fonts, losslessly

          
Identical font subsets embedded once per figure are merged into one; unused tables are dropped. Optionally, glyph outlines no text uses are emptied too.

        

        

          
          
Private by construction

          
The engine is compiled to WebAssembly and runs in this tab. No upload, no server, no tracking: the PDF you drop is read and written inside your browser and sent nowhere.

        

      

    


    

      

        
Leaves alone what it can't prove

        
Every change is either provably lossless or an image recompression within the quality you chose. Anything else passes through byte for byte, and the log says why.

      

      
    
        
  • Signed and protected documents are refused rather than silently stripped of their signature or protection.
    • 
        
  • Forms, annotations and accessibility tags are kept, never flattened or dropped.
    • 
        
  • Encodings it can't decode with confidence (JPEG 2000, unusual color spaces, predictors) stay exactly as they were.
    • 
        
  • Hostile files are bounded: decompression, image sizes and font programs all run under hard limits.
    • 
      

    


    

      
Use it from the command line or in your code

      
The same engine ships as a Rust crate and as an npm package, each with a command-line tool and a library.


      

        

          
Rust

          
cargo install pdfdiet

          
cargo add pdfdiet

        

        
Rust 1.88 or later. cargo install gives you the command-line tool; as a library, add default-features = false to leave the argument parser out. API documentation is on docs.rs.

        

          

            
            
            
          

          
# see what a file is made of: images, encodings, measured DPI
pdfdiet inspect report.pdf

# compress (defaults: --dpi 150 --quality 80)
pdfdiet compress report.pdf -o report.small.pdf

# opt-ins
pdfdiet compress in.pdf -o out.pdf --subset-outlines --strip-jpeg-metadata

          
use pdfdiet::{compress_bytes, CompressOptions};

let input = std::fs::read("in.pdf")?;
let opts = CompressOptions::default().target_dpi(150.0).jpeg_quality(80);
let (output, stats) = compress_bytes(&input, &opts)?;
std::fs::write("out.pdf", output)?;
// what was changed, and what was left alone and why
for line in &stats.log { println!("{line}"); }

        

      


      

        

          
JavaScript

          
npm install @sawapi/pdfdiet

        

        
Node 22 or later, and current browsers through any bundler. One WebAssembly file (about 550 KB gzipped), no native binaries, TypeScript types included. The full API is in the package README.

        

          

            
            
            
            
          

          
# no install needed
npx @sawapi/pdfdiet inspect report.pdf
npx @sawapi/pdfdiet compress report.pdf -o report.small.pdf

          
import { compress } from "@sawapi/pdfdiet";
import { readFileSync, writeFileSync } from "node:fs";

const res = compress(readFileSync("in.pdf"), { dpi: 150, quality: 80 });
writeFileSync("out.pdf", res.output);
console.log(res.log.join("\n"));

          
import { init, compress } from "@sawapi/pdfdiet/web";

await init(); // loads the .wasm file once
const res = compress(new Uint8Array(await file.arrayBuffer()));
const blob = new Blob([res.output], { type: "application/pdf" });
